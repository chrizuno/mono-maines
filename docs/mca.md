# Minecraft Comes Alive (MCA)

## Crescimento e Ciclo de Vida

### Tempo até a Vida Adulta
Tempo que leva para um bebê crescer até se tornar um adulto

```
"villagerMaxAgeTime": 8856000   // 360 Dias (2 Anos)
```

### Crescimento de Bebês
Tempo necessário para que possa colocar um bebê (item) no chão e ele possa crescer

```
"babyItemGrowUpTime": 168000    // 7 dias 
```

## Sistema Social e Relacionamentos


### Amizade

``` 
"heartsToBeConsideredAsFriend": 50   // original: 40
```

### Relacionamentos Românticos

```
"bouquetHeartsRequirement": 25       // original: 10

```


## Defesa das Vilas
Guardas são mais agressivos com os monstros

```
"guardsTargetMonsters": true         // original: false
```
